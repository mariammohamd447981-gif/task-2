Introduction

Javascript تعتبر (JavaScript) من اشهر لغات البرمجه المستخدمه في تطوير الويب حيث تسمح المبرمج بإنشاء صفحات تستجيب لنقرات المستخدم وتتحقق من البيانات التي يدخلها وتغير محتوي المعروض دون الحاجه الي اعادت تحميل الصفحه في كثير من الحالات فعلي سبيل المثال يمكن استخدامها لانشاء قوائم تفاعليه وازرار لتغير الالوان ونماذج تسجيل الدخول وسلال التسوق الالكترونيه وغيرها من التطبيقات التي تجعل تجربه المستخدم اكثر سهوله وفاعليه

شرح Javascript

Javascript هي لغة برمجة تعمل داخل متصفحات الويب الحديثة (مثل Google Chrome و Firefox) أو خارجها في بيئات مثل Node.js. تتيح تنفيذ أوامر معينة عند وقوع أحداث محددة (مثل نقر زر أو إدخال نص). ملاحظة: تختلف تماماً عن لغة Java على الرغم من التشابه في الاسم. يقوم المتصفح أولاً بقراءة HTML لبناء الهيكل، ثم يطبق قواعد CSS لتنسيقه، وأخيراً ينفذ تعليمات JavaScript. تعتمد على مفهومين أساسيين للتحكم في الصفحة: يمثل عناصر الصفحة في هيكل برمجي يتيح لـ JavaScript الوصول إلى أي عنصر (مثل فقرة أو زر) وتغيير محتواه أو خصائصه أثناء التشغيل.
